Mission & methodology

Why this site exists, and how it’s built

Environmento is an independent, volunteer-run education project. It is not affiliated with Howard County government, and it is not a substitute for the county’s official tools.

Mission

Make the county’s own data legible

Howard County already collects and publishes serious climate, flood, and land-use data. The problem isn’t a lack of information — it’s that most of it lives in dashboards and GIS layers built for planners and engineers, not for a resident trying to answer a simple question: does my street flood, does my neighborhood run hot, and what, if anything, is being done about it.

This site exists to answer those questions in plain language, with every claim traceable back to a named public source, and to point residents toward the county’s own tools for anything that requires property-level precision rather than a countywide overview.

Methodology

Where the data comes from, and its limits

  • Sources used
    Exactly three: Howard County Climate Forward (climateforward.howardcountymd.gov), the Howard County Open Data / GIS portal (data.howardcountymd.gov and opendata.howardcountymd.gov), and the Maryland iMAP GIS Data Catalog with FEMA flood maps (data.imap.maryland.gov and mdfloodmaps.net). No other datasets, models, or estimates are used.
  • How hotspots are chosen
    Each entry in the hotspots map corresponds to a location specifically named or ranked in one of the three sources above — not a general assumption about a neighborhood. Severity labels (high / elevated) reflect the relative language used in the source material, not a new scoring system we invented.
  • What this site doesn’t do
    It does not generate new flood models, does not make property-level hazard determinations, and does not replace the DFIRM viewer or FEMA flood maps for insurance or permitting purposes. Anywhere this site says "flood risk," treat it as a pointer to go check the official map for your address.
  • Update cadence
    Content is reviewed against the three sources on an ongoing basis. Hotspot data lives in a single file (data/hotspots.json) so it can be corrected or expanded without touching page markup. This page and the site footer show the date of the last review.
